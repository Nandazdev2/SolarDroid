## [1.0.0] - 2026-07-27

### Added
- Initial release of SolarDroid
- Code editor with Lua syntax support
- Real-time console output
- Project manager for organizing Solar2D apps
- File tree navigation for project files
- Live preview screen for testing apps
- APK compilation and export
- Support for Android API 21 (Android 5.0) and above
- APK signing with integrated keystore management
- Hardware acceleration support
- Material Design UI theme

### Features Included
- ✅ Simple code editor
- ✅ Console for debugging
- ✅ Project manager
- ✅ File tree browser
- ✅ Game/app preview screen
- ✅ APK compilation system
- ✅ Full Solar2D runtime integration
- ✅ OpenGL ES 2.0 graphics support

### Known Limitations
- UI is functional but not polished
- Limited autocomplete functionality
- No plugin system yet
- No built-in Git integration
- Single device testing only

## Changelog Format Guide

When adding changes to this file, use the following format:

```
### Added
- New features

### Changed
- Changes in existing functionality

### Deprecated
- Soon-to-be removed features

### Removed
- Now removed features

### Fixed
- Any bug fixes

### Security
- In case of vulnerabilities
```

## How to Report Changes

To keep this changelog updated:

1. **During Development:** Update this file when making significant changes
2. **Before Release:** Ensure all changes are documented
3. **In PRs:** Include changelog updates for user-facing changes
4. **Commit Message:** Reference the changelog section in your commits

### Example PR Update

```markdown
## Changes

- Added feature X
- Fixed bug Y
- Improved performance

## Changelog Update

```md
### Added
- New feature X for improving Z

### Fixed
- Fixed crash when opening large files
```
```

## Release Process

1. **Update Version:** Increment version number (MAJOR.MINOR.PATCH)
2. **Update Changelog:** Move [Unreleased] changes to new version
3. **Tag Release:** Create git tag for the release
4. **Build & Test:** Ensure all tests pass
5. **Publish:** Release on GitHub and other platforms
